# 🚀 INICIO RÁPIDO - Para el Desarrollador

## ⚡ Desplegar AHORA (3 minutos)

### Opción A: Netlify (MÁS FÁCIL)
1. Ve a: https://app.netlify.com/drop
2. Arrastra la carpeta `dist` a la página
3. Copia la URL que te da
4. ¡Compártela con tus amigos!

### Opción B: Script Automático
```powershell
.\deploy.ps1
```
Elige "S" para servidor local o "N" para solo preparar archivos.

## 📱 Cómo Instalan tus Amigos

**Android (Chrome/Edge):**
- Abrir URL → Tocar "Instalar" → Listo

**iPhone (Safari):**
- Abrir URL → Botón compartir (□↑) → "Añadir a pantalla de inicio"
